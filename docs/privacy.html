このアプリについて

トレッドミル（以下、本アプリ）は、トレッドミルでのウォーキング・ランニングを記録するアプリです。運営者は Soichiro Inatani です。アカウント登録は不要です。

取り扱う情報と利用目的

入力した体重・身長、速度・傾斜、単位、音声ガイドなどの設定を端末内に保存します。体重は消費カロリーの推定に使います。身長はプロフィール情報として保持します。

ワークアウトの日時、時間、速度・傾斜・歩行または走行の区間、距離、推定消費カロリー、上昇量、メニュー、距離の補正情報、歩数を端末内に保存し、計測表示・履歴・グラフ・週の集計に使います。

ヘルスケアとの連携

ユーザーが許可した場合に限り、HealthKit を通じて体重・身長を読み込みます。履歴の復元では、このアプリがヘルスケアへ保存したワークアウト・歩行＋走行距離・アクティブエネルギーを読み込みます。

保存を選んだ場合、屋内ウォーキングまたは屋内ランニングとして、ワークアウト・距離・アクティブエネルギーをヘルスケアへ書き込みます。復元のため、体重、歩数、速度・傾斜の区間、メニュー、距離補正などの追加情報もワークアウトや関連するサンプルに保存します。

健康・運動データを広告、販売、ユーザー追跡のために利用しません。HealthKit の許可はヘルスケアまたは iOS の設定から変更できます。読み取り・書き込みを許可しなくても、手入力による記録は利用できます。

歩数・音声・位置情報

許可された場合、Core Motion を使ってワークアウト中の歩数とピッチを取得します。iPhone をトレッドミルの台に置いたままでは、歩数を正しく取得できない場合があります。

音声ガイドには Apple の音声合成機能を使います。マイクでの録音は行いません。GPS や位置情報は取得しません。

外部送信・広告・解析

本アプリは、運営者が管理するサーバーへの健康・運動データの送信を行いません。広告 SDK、行動解析 SDK、ユーザー追跡機能は組み込んでいません。

アプリ独自に iCloud / CloudKit へ健康情報を保存しません。Apple のヘルスケア自体の同期や、OS のバックアップ・診断情報は、ユーザーの端末設定と Apple のサービスに従って管理されます。

サポート・プライバシーページをブラウザで開くと GitHub Pages に接続します。Webページの配信に伴う IP アドレスなどの処理は GitHub のプライバシーポリシーに従います。問い合わせメールを送信した場合、運営者は送信されたメールアドレスと内容を、問い合わせ対応のために利用します。

保存・削除・許可の取り消し

アプリ内の履歴は、履歴画面で左にスワイプして削除できます。アプリを削除すると、アプリ内に保存された履歴と設定も削除されます。OS のバックアップに含まれる情報は、端末のバックアップ設定で管理してください。

アプリ内の履歴削除やアプリの削除では、ヘルスケアに保存済みの記録は削除されません。ヘルスケアアプリで本アプリのデータを選び、必要な記録を削除してください。ヘルスケアに残った記録は、復元操作で再び取り込まれる場合があります。

ヘルスケアとモーションの許可は、iOS またはヘルスケアの設定で取り消せます。運営者は端末内やヘルスケアの記録へ遠隔アクセスできません。メールでの問い合わせでは、健康データを添付する必要はありません。

問い合わせメールは対応に必要な期間保持し、不要になった情報は削除します。問い合わせ内容の削除を希望する場合は、サポート窓口へご連絡ください。

機能や取り扱い方法の変更に応じて本ポリシーを更新する場合があります。最新の内容と更新日は、このページとアプリ内で確認できます。
