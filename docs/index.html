TREADMILL TRACKER

今日も、一歩先へ。

屋内でも、積み重ねよう。
トレッドミルでのウォーキング・ランニングを、見やすい数字で記録。

自分のペースで、記録する。

速度と傾斜を入力して、時間・距離・推定消費カロリーを確認。メニューと音声ガイドで、日々の室内トレーニングを支えます。

対応環境：iOS 17以降のiPhone。アカウント登録は不要です。
